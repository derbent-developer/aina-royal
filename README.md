# Айна Рояль — сайт салона красоты

Одностраничный сайт студии красоты **«Айна Рояль» / Aina Royal Studio** (Дербент, ул. Владимира Ленина, 6).
Без сборки и зависимостей — обычные HTML, CSS и JavaScript.

**Сайт в интернете:** адрес появится здесь после подключения Cloudflare Pages
(старый https://derbent-developer.github.io/aina-royal/ работает, пока репозиторий публичный)

## Как обновить сайт

Внесите изменения (обычно достаточно поправить `assets/js/data.js`), затем
**дважды щёлкните по файлу `Обновить сайт.command`** в этой папке.

Он спросит, что поменяли, сам сдвинет версию стилей и скриптов
(чтобы у посетителей не остался старый кэш), отправит всё на GitHub
и предложит открыть сайт. Через 1–2 минуты изменения будут в интернете.

Если macOS откажется запускать файл — правый клик → «Открыть» → «Открыть».
Разрешение нужно дать только один раз.

## Как открыть

Двойным щелчком по `index.html` — или, чтобы всё работало наверняка, локальным сервером:

```bash
cd ~/Desktop/"Айна Рояль" && python3 -m http.server 8788
```

Затем откройте http://localhost:8788

## Что внутри

```
index.html              разметка всех секций
assets/css/style.css    оформление и анимации
assets/js/data.js       ← ВСЁ РЕДАКТИРУЕМОЕ: цены, мастера, фото, отзывы, контакты
assets/js/app.js        логика: скролл-анимации, форма записи, галерея, слайдер
assets/photos/          59 фотографий салона (оригиналы)
assets/photos/sm/       те же кадры на 640 px — для телефонов
assets/photos/xs/       те же кадры на 400 px — для плиток галереи
Обновить сайт.command   двойной щелчок — и изменения уезжают на сайт
```

Папки `sm` и `xs` создаются один раз. Если добавите новое фото в `assets/photos/`,
сделайте для него уменьшенные копии:

```bash
cd ~/Desktop/"Айна Рояль"
sips --resampleWidth 640 -s formatOptions 66 assets/photos/НОВОЕ.jpg --out assets/photos/sm/НОВОЕ.jpg
sips --resampleWidth 400 -s formatOptions 62 assets/photos/НОВОЕ.jpg --out assets/photos/xs/НОВОЕ.jpg
```

и добавьте его размеры в `PHOTO_DIMS` в `data.js`. Без уменьшенных копий сайт
тоже работает — просто телефон скачает оригинал.

## Что уже сделано

- **Обложка в стиле Apple** — фотография «сжимается» и уходит вглубь при прокрутке, заголовок выезжает построчно.
- **Блок «О салоне»** — кадры сменяют друг друга по мере скролла, к каждому свой текст (тот самый эффект, как на apple.com).
- **Лента работ** — едет вбок, пока страница прокручивается вниз.
- **Услуги** — полный прайс с Яндекс Карт, 8 категорий, 152 позиции, вкладки и «показать все».
- **Мастера** — карточки с рейтингами; нажатие подставляет мастера в форму записи.
- **Онлайн-запись** — 4 шага: услуга → мастер → дата и время → контакты. В конце заявка уходит в WhatsApp салона одним нажатием.
- **Галерея** — 45 фото, фильтры по категориям, просмотр во весь экран (стрелки и Esc работают).
- **Отзывы** — с Яндекс Карт, плюс полоски оценок по темам.
- **Карта** — подгружается только по нажатию, чтобы Яндекс не грузил скрипты на всех подряд.
- Адаптив под телефон и планшет, поддержка «уменьшенной анимации» в системных настройках.

## Оптимизация под телефоны

- **Три размера каждой фотографии.** Браузер сам берёт нужный: плитки галереи —
  400 px (~40 КБ), лента работ — 640 px (~93 КБ), обложка во весь экран — оригинал.
  До этого телефон тянул оригиналы по 165 КБ везде.
- **Размеры прописаны в разметке**, поэтому страница не «прыгает», пока грузятся фото.
- **Вкладки услуг и фильтры галереи** на телефоне едут вбок, а не разваливаются на пять рядов.
- **Кнопки не меньше 44 px** — попасть пальцем можно не целясь.
- Кнопки обложки и формы записи растянуты на всю ширину, шаги записи сжаты в колонки.
- Плавающая кнопка «Записаться» учитывает «челюсть» iPhone (`safe-area-inset`).
- Поля ввода с шрифтом 16 px — iOS не приближает экран при нажатии.
- Обложка использует `100svh`, поэтому не прыгает, когда в Safari прячется адресная строка.
- Отдельная раскладка для телефона в горизонтальной ориентации.
- На мониторах шире 1700 px контент расширяется до 1400 px и галерея идёт в 5 колонок,
  шире 2200 px — 1600 px и 6 колонок. Иначе сайт терялся узкой полосой посередине.

## Что стоит поправить перед публикацией

1. **Направления мастеров.** На Яндекс Картах публикуются только имена и рейтинги, поэтому в `data.js`
   у Фариды и Зины стоит нейтральное «Специалист «Айна Рояль»». Впишите реальные направления —
   и заодно добавьте остальных мастеров, в карточке онлайн-записи видны не все.

2. **Фотографии.** Взяты из галереи салона на Яндекс Картах — часть загружали гости.
   Для сайта лучше заменить на свои оригиналы в хорошем разрешении: просто положите файлы
   в `assets/photos/` и поправьте списки в `data.js`.

3. **Форма записи** сейчас без сервера: она собирает заявку и передаёт её в WhatsApp.
   Если нужна настоящая онлайн-запись с занятыми слотами — подключается YCLIENTS или
   виджет Яндекса, место для этого в `app.js`, функция `submit()`.

4. **Соцсети.** В `data.js` есть пустое поле `instagram` — вставьте ссылку, если нужна кнопка.

5. **Цены** перенесены с Яндекс Карт на 8 сентября 2026 года — сверьте перед запуском.

## Приватность

Репозиторий закрыт: историю правок, этот файл, скрипт обновления и структуру
проекта посторонние не видят.

**Но сам код сайта скрыть нельзя.** Браузер обязан скачать `index.html`,
`style.css`, `app.js` и `data.js`, чтобы показать страницу. Любой посетитель
может нажать F12 или «Исходный код страницы» и всё это прочитать — включая
весь прайс из `data.js`. Так устроен любой сайт, не только этот.

Поэтому в файлы сайта нельзя класть то, что не должно попасть наружу:
внутренние цены, телефоны сотрудников, пароли, ключи от сервисов.
Всё, что лежит в `assets/`, публично по определению.

## Почему хостинг не на GitHub

GitHub Pages не работает с приватным репозиторием на бесплатном плане —
сайт просто перестаёт открываться. Поэтому страницы отдаёт Cloudflare Pages:
он бесплатный, дружит с приватными репозиториями и сам пересобирает сайт
после каждой отправки.

Схема работы не изменилась: двойной щелчок по `Обновить сайт.command`
отправляет правки на GitHub, Cloudflare подхватывает их сам за минуту.
